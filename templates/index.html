Authenticates the same way a plain ssh username@host would - via your running ssh-agent and/or default keys in ~/.ssh/. The server's public key must already be in that user's ~/.ssh/authorized_keys. This app never writes, deletes, or modifies anything on the server - every remote command is read-only, and unknown SSH host keys are rejected rather than auto-trusted.
